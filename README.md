# EvolutionAE
A bad addon for compat between AE2 and GregTechCEu Modern.

### Features
- A singular pattern provider
- Item of Item

### Where download?
- It's available on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/evolutionae/files/latest) and [GitHub](https://github.com/CreateTechified/EvolutionAE/releases/latest).
